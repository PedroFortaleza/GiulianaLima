# Dra. Giuliana Lima · prévia de site

Site estático, sem instalação de pacotes. Prévia conceitual baseada em informações públicas, não uma publicação oficial da profissional.

## Executar

Com Node.js 20 ou superior:

```bash
node serve.mjs
```

Abra http://127.0.0.1:3001. Também é possível abrir `index.html` diretamente no navegador. O servidor adiciona `X-Robots-Tag: noindex, nofollow`.
